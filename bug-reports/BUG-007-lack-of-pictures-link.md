# BUG-007. Отсутствует ссылка на сервис с картинками в виде теста "еще картинки"

**Severity:** Major  
**Priority:** Medium  
**Компонент:** Голосовой помощник  
**Связанный тест-кейс:** TC-4 "Картинки", шаг 3
**Воспроизводимость:** Всегда (3/3)  

## Окружение

- Устройство: iPhone 14
- ОС: iOS 26.5.2
- Сеть: Wi-Fi

## Предусловия

1. Приложение установлено и запущено.
2. Пользователь авторизован.
3. Открыт основной диалог с голосовым помощником.
4. Звук включён, громкость > 0.
5. Введен запрос "Картинки <выбранный запрос>"
6. Тапнули на первую картинку

## Шаги воспроизведения

1. Вернуться в приложение, тапнуть на ссылку "еще картинки"

## Ожидаемый результат

- Открывается сервис с картинками по выбранному запросу.

## Фактический результат

- В чате нет слов "еще картинки", которые работали бы как ссылка на сервис с картинками
- В 2 из 3 случаев ассистент в конце своего ответа предлагает другие сайты для поиска картинок с ссылками на них.
