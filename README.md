# Voice Assistant — Bug Reports (учебный проект)

Учебный проект по ручному тестированию голосового ассистента.
Цель — отработать тест-дизайн и оформление баг-репортов.

Тестирование проводилось на публично доступной версии продукта в качестве обычного пользователя.

## Структура проекта

- `bug-reports/` - папка с баг-репортами
- `test_cases.md` - файл с 6 тест-кейсами, покрывающими разные сценарии голосового ассистента.

## Методика

- Ручное тестирование, запросы голосом и текстом.
- Фиксация поведения дословно (включая произносимые фразы).
- При нерегулярных результатах проводилось больше 3 тестов (6 или 12)
- Окружение: iPhone 14, iOS 26.5.2, приложение голосового ассистента.

## Примечание

Все данные — личные наблюдения автора в учебных целях.
Не является официальным отчётом о безопасности или качестве продукта.
Материалы, содержащие узнаваемые элементы продукта, не приложены.
